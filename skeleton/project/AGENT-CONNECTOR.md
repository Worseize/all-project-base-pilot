# Коннектор агента проекта

## Кто есть на узле

- **Админ узла:** гейт на push, файрвол, журналы, бэкап, merge в `main`.
- **Агент проекта:** только свой проект и ветка `review`.
- Продукт — отдельный проект; в репозитории шаблона продукта нет.

## Что можно и чего нельзя

Можно: пушить в `review`, читать свой репозиторий, пользоваться `test.sh`.

Нельзя: писать в `main`, трогать чужие проекты, менять юниты и файрвол,
читать секреты узла.

## Как задать вопрос узлу

Через файл-сообщение по схеме шины: `from`, `to`, `kind`, `topic`,
`requires`. Агент не пишет другим агентам проектов.

## Что считается «готово»

Пуш в `review`, зелёная проверка, файл приёмки. Закрытие задачи — не
действие агента проекта.

## Роли продукта

Продукт живёт по контракту отдельного проекта. Шаблон даёт правила, гейт
и приёмку; кода продукта в нём нет.
