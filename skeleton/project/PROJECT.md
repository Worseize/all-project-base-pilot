# PROJECT: project skeleton

Минимальный профиль проекта. Заполняется агентом проекта; узел проверяет
наличие обязательных разделов.

## Назначение

Что делает продукт и для кого. Не описывать здесь шаблон узла.

## Стек

Язык и runtime продукта. Узел не диктует стек.

## Команды

```bash
./run
./test.sh
```

## Границы

- Продукт живёт в своём репозитории и не правит узел.
- Секреты — вне репозитория.
- Порты наружу не открываются.

## Данные

- Данные продукта — вне кода и вне git.
- Путь данных задаётся администратором узла.

## Окружения

- `local` — разработка агента.
- `review` — приёмка узла.
- `prod` — запуск под отдельным пользователем.

## Исключения

- Язык и зависимости продукта выбирает проект.
- Служебные файлы узла не входят в проект.
