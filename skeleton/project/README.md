# Project skeleton

Минимальный проект для онбординга на админ-узле.

- `run` — единственная точка запуска; `100755` в git.
- `PROJECT.md` — профиль проекта, данные, сайт, журналы.
- `test.sh` — контракт проверки; `100755` в git, зелёный на пустом `PROJECT_DATA_DIR`.
- `health` — 0/1 и одна строка; узел запускает раз в минуту.
- `.gitignore` — артефакты, данные и секреты.

Не копируйте сюда инструменты узла, `cmd/`, `verify.py` и деплой-скрипты.
