# Project skeleton

Минимальный проект для онбординга на админ-узле.

- `run` — единственная точка запуска.
- `PROJECT.md` — профиль проекта.
- `test.sh` — контракт проверки; gate запускает его, если он есть.
- `.gitignore` — артефакты и секреты.

Не копируйте сюда инструменты узла, `cmd/`, `verify.py` и деплой-скрипты.
