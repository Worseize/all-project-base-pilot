# AGENTS.md

Этот репозиторий — шаблон архитектуры крупного проекта. Стек по умолчанию —
Go, только стандартная библиотека. Никаких npm, Node.js и сторонних пакетов.
Перед первой правкой прочитай `RULES.md` целиком: десять правил обязательны
на каждом шаге, цикл шага — семь ворот, закрытие задачи — по определению
готовности.

Короткий индекс (полные формулировки и проверки — в `RULES.md`):

1. Чистый код, имена и уборка
2. Все новые фичи — в схемах
3. Тесты под каждую фичу
4. Ноль зависимостей: Go
5. Схемы — источник истины
6. Микроблоки и ООП
7. Читать перед записью
8. Пять минут — стоп
9. Проверять живо
10. Данные и секреты

Закрывая задачу, обнови схемы и перерисуй картинки:
`python verify.py --update-schemes`.

Стратегия, дорожная карта и очередь улучшений — `STRATEGY.md`.
Схемы: `docs/scheme-strategy.png`, `docs/scheme-roadmap.png` — генерируются
локально, в git не хранятся.

Профиль проекта — `PROJECT.md`, карточка фичи — `FEATURE.md`,
быстрый старт — `README.md`. Процесс и red gate — `PROCESS.md`,
схема — `docs/scheme-process.png` (генерируется).
Перед закрытием: `python verify.py` — только зелёный; мёртвый код —
`go run ./cmd/deadcode`; запись в `JOURNAL.md` или `docs/adr/`.
