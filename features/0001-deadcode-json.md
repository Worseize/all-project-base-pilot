# FEATURE: deadcode -json

Пилотная фича шаблона. Одна карточка — один вход в правила 2 и 3.

## Цель

Дать CI и внешним отчётам машиночитаемый вывод `deadcode`: JSON-массив
находок вместо текста. Поведение exit code не меняется: находки — 1,
чисто — 0.

## Схема плана

Затрагивается только `cmd/deadcode`:

- `finding` получает JSON-теги;
- `main` получает флаг `-json`;
- текстовый вывод и AST-логика не меняются;
- `verify.py` уже запускает `deadcode`, отдельная команда не нужна;
- схема процесса не меняется.

## Контракт

```bash
go run ./cmd/deadcode -json [root]
```

- stdout: JSON-массив `[{"pos":"...","kind":"func","name":"..."}]`.
- Чисто: `[]`, exit 0.
- Находки: exit 1.
- Ошибка разбора/обхода: stderr, exit 2.
- Поля: `pos`, `kind`, `name`.
- Текстовый режим без `-json` совместим.

## Тесты

- `TestJSONEncoding` — массив находок и пустой массив.
- Существующие тесты AST: func/type/var/const/method/interface/generated.
- `go test ./...`, `go run ./cmd/deadcode -json`, `verify.py`.
