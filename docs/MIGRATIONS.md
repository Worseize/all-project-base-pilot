# Миграции

Версия 0.9.18 · 22.10.2026

Миграции — append-only. Старые шаги не редактируются и не удаляются:
иначе окружения, применявшие их, расходятся с новыми.

## Правила

- Один шаг — одно изменение схемы или данных.
- Номер/имя шага уникальны и не меняются после применения.
- Шаг идемпотентен или защищён версией схемы.
- Данные переносятся копией, а не «на месте», если есть риск.
- Перед миграцией — бэкап и проверка восстановления.
- Откат — отдельный шаг вперёд, а не правка истории.

## Проверка перед выкаткой

- [ ] Схема поднимается с нуля.
- [ ] Схема поднимается с предыдущей версии.
- [ ] Повторный запуск не ломает данные.
- [ ] Старые шаги не изменены.
- [ ] Есть план отката/forward-fix.
- [ ] Бэкап снят и восстановление проверено.

## Данные

- Секреты и персональные данные не попадают в тестовые дампы.
- Для проверки — копия, а не прод.
- После миграции — живая проверка ключевых записей.

## Границы

Конкретный инструмент миграций зависит от продукта. Шаблон фиксирует
политику, а не движок.
