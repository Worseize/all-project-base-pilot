# Ротация сессии

Состояние живёт в репозитории, история чата — дорогой кэш. Новая сессия
стартует пустой и поднимает состояние по протоколу.

## Перед переходом

1. Почта разобрана: `inbox` пуст, ответы в `outbox`, прочтение отмечено.
2. Долги на доске честные; «не сделано» в ответе — только строки доски.
3. Работа доведена до коммита или заведена долгом; `git status` чист
   (кроме файлов, которые в git не входят).
4. Реестры обновлены: `DEBTS.md`, `docs/REQUESTS.md`, `JOURNAL.md`.

## Передача состояния

Читать в новой сессии: `AGENTS.md`, `docs/TO-AGENTS-ONBOARDING.md`,
`DEBTS.md`, `docs/WAKE-LOG.md`, `docs/REQUESTS.md`, хвост `JOURNAL.md`.

## Новая сессия

Старт по протоколу `docs/TO-AGENTS-ONBOARDING.md`; первое пробуждение по
расписанию закрывает минимум один долг (`wake-debts`).

## Проверка

`verify.py` → `rotation`: разделы на месте, протокол ссылается на
onboarding и `wake-debts`; инструкция не заменяет файлы генераторов.
