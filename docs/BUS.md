# Шина агентов: почта без суточных лимитов

Агент читает только свой ящик: `mailbox/inbox` → обработка → `mailbox/processed`.
Ответ — файл в `mailbox/outbox` с шапкой (`id`, `from`, `to`, `kind`,
`topic`, `requires`). Прочтение подтверждается маркером `.checked`.

Суточных лимитов нет: ограничения только формат и размер — одно сообщение
≤ 16 КБ, один адресат, без секретов и личных данных. Отклонённое письмо
лежит в `mailbox/rejected` с причиной; молча терять письмо нельзя. Если
канал отбил письмо — это дефект канала, а не повод замолчать.

## Проверка

`verify.py` → `bus-limits`: документ описывает шину без суточных лимитов,
и нигде в шаблоне не объявлен счётчик «N в сутки».
