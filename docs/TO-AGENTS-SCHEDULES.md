# Расписание: в заголовке — к какому чату оно относится

Аудитория: агенты bot-agent, template-agent, portfolio-agent.

## Правило

Создавая расписание (`scheduler`), в **заголовке** укажи, к какому чату
оно относится. Формат:

```
<имя агента>: <что делает>
```

Примеры:

| Правильно | Неправильно |
| --- | --- |
| `bot-agent: опрос почты` | `опрос почты` |
| `template-agent: проверка issues` | `проверка` |
| `portfolio-agent: отчёт по сайту` | `каждый час` |

## Почему

1. **Расписание принадлежит чату, в котором создано.** Оно не «общее»:
   сработав, оно будит именно этот чат.
2. Владелец видит список расписаний без контекста: «опрос почты»
   в трёх чатах — три одинаковые строки, и неясно, чья какая.
3. Если расписание не нужно, его надо где-то найти, чтобы убрать.
   Без имени агента это поиск наугад.

## Границы

1. Ты создаёшь расписание **только в своём чате**. Создавать его в чужом
   чате нельзя: это способ разбудить другого агента в обход владельца.
2. Заголовок — не место для инструкций и паролей. Только «кто» и «что».
3. Расписание — это не задание. Работа остаётся задачей владельца;
   расписание лишь говорит, когда посмотреть.
4. В простое не просыпайся: если расписание всё же нужно, ставь интервал
   не меньше 4 часов и первым шагом проверяй `mailbox\check.ps1`
   (`EMPTY` — ответ «idle» и конец).

## Проверка

Если сомневаешься, годится ли заголовок, прочитай его вслух: понятно ли,
**чей** это чат? Если нет — переименуй.

## Только идентификатор, без «Агент шаблона»

Владелец дважды видел расписания с заголовками вроде
«Агент шаблона - Проверка сообщений от агента узла» и просил так больше
не делать. Причина: в списке расписаний нужен **идентификатор**, по
которому сразу видно чат, а не словесное описание.

Правильно:

```
template-agent: проверка почты
portfolio-agent: проверка почты
bot-agent: опрос почты
```

Неправильно (и будет поймано проверкой):

```
Агент шаблона - Проверка сообщений
Проверка сообщений от агента узла
Шаблон: проверка
```

Правило: `<идентификатор>:` — ровно так, как агент назван в
`docs/NAMES.md`. Русские формы («агент шаблона», «агент портфолио»)
не годятся: они не совпадают с конфигом и не находятся поиском.

Проверка: `deploy\check-schedules.ps1` — читает `~/.dsh/storages/schedule.json`,
сопоставляет сессию с репозиторием агента и падает, если заголовок
не начинается с нужного идентификатора.
