# Архив прецедентов AGENTS.md

Истории правил: что сломалось, почему появилось правило, какая проверка
родилась. В `AGENTS.md` — только действующие правила.

## 2026-10-26 · Почта до работы

Владелец писал вручную, потому что агент не читал `mailbox/inbox` без
напоминания. Правило: первое действие — `check.ps1`; `PENDING` — прочитать
до работы. Проверка: `check.ps1` в локальном `pre-push`.

## 2026-10-26 · Три попытки — эскалация

Фикстура манифеста падала на `missing mode missing`; три попытки не дали
результата. Правило: после трёх — escalation conductor с точным текстом.
Проверка: `AGENTS.md` и `check-contracts.ps1`.

## 2026-10-26 · Проснулся — пересчитай долги

После письма и чужого коммита реестр отставал. Правило: каждое пробуждение
пересчитывает `DEBTS.md`, report содержит `+N / −M / K`.
Проверка: `verify.py` и `DEBTS.md`.

## 2026-10-26 · Каждый ответ закрывает долг

Открытые долги оставались открытыми, ответы были «отчётом о фронте».
Правило: каждый ответ закрывает хотя бы один живой проверкой.
Проверка: `DEBTS.md` и `reply-debts` (у узла).

## 2026-10-26 · Доска долгов

У агентов были разные форматы. Правило: `DEBTS.md`, три раздела, шесть
колонок, теги D/W/L. Проверка: `tests/test_verify.py`.

## 2026-10-26 · Колонка # в сообщении о долгах

Отчёт пришёл без `#`; строки нельзя было сопоставить. Правило: любая
таблица долгов начинается с `#`; `deploy/debt-table.py`.
Проверка: тест форматтера.

## 2026-10-26 · Watchdog от root

`health-check.sh` делает `runuser`; `User=app` без sudoers не может.
Решение: root + `ProtectSystem`, `ReadWritePaths`, `NoNewPrivileges`,
`EnvironmentFile`. ADR 0006. Проверка: unit-тест в `tests/test_verify.py`.

## 2026-10-29 · Расписание — по имени чата

Владелец дважды видел «опрос почты» без идентификатора и не мог понять,
чей это чат. Правило: `<агент>: что делает`, только свой чат, не задание.
Проверка: `verify.py` → `schedules`.
