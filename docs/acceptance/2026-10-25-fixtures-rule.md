# Правило про фикстуры

1. Дефект, найденный живым проектом, закрывается тестом в CI шаблона: фикстура → действие → ожидаемый результат. Без продукта, без имён, без доступа к чужому хосту.
2. В issue запрещены формулировки «проверим на реальном проекте», «ждём переезд», «закроем, когда проект запустит».
3. Живой проект в issue — только источник: что сломалось и при каких условиях.
4. Если сценарий не воспроизводится на фикстуре — проверка сформулирована неверно: сначала переформулировать, потом кодить.

Проверка в гейте: `verify.py` требует наличие раздела «Проверка — фикстурами» в `AGENTS.md`, `PROCESS.md` и `docs/AGENT-CONTRACT.md`; тест краснеет при отсутствии.
