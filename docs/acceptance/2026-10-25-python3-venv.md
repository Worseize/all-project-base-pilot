# Зависимости узла: python3-venv в HOST.md, selftest и понятный отказ

Манифест проекта объявляет `deps`, узел создаёт окружение. Но пакета, без которого это работает, в требованиях узла нет.

Наблюдаемое: сценарий `deps/build` в приёмке падает на чистом хосте с `ensurepip is not available`, потому что не установлен `python3-venv`. В CI GitHub пакет есть, поэтому там зелено, а на обычном сервере — нет.

Нужно:

1. В `docs/HOST.md` — список пакетов узла: `python3-venv`, `git`, `curl`, `caddy` (если сайт), с формулировкой «пакет нужен, если у проектов есть зависимости этого типа».
2. В `deploy/selftest.sh` — проверка: `python3 -m venv` создаёт окружение во временном каталоге, каталог убирается; красная проверка «поставь python3-venv».
3. В приёмке — если зависимости недоступны, сценарий падает с ясным текстом «нет python3-venv».
4. В bootstrap — установка пакета идемпотентна.

Критерий: на чистом Ubuntu 24.04 `selftest` краснеет с понятным текстом; после установки пакета — зелёный; приёмка зелёная.
