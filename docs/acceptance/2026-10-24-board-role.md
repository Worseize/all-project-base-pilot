# Правило доски: issue закрывает только conductor, агент правит только шаблон

Правило: исполнитель не управляет трекером, по которому его принимают.

Нельзя:
- открывать и закрывать issues;
- менять метки, исполнителей, заголовок и тело issue;
- отмечать задачи выполненными любым другим способом.

Можно:
- читать issues и комментарии к ним;
- писать комментарий-отчёт о сделанном;
- если задача, по твоему мнению, закрыта — сказать это в комментарии, но не закрывать.

Закрывает issue только conductor, после проверки результата. Иначе журнал приёмки перестаёт быть доказательством: исполнитель сам подтверждает свою работу.

Реализация: правило записать в документацию шаблона (процесс работы с задачами) как обязательное, а не рекомендацию.
