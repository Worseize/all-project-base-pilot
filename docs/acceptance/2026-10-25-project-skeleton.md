# Скелет проекта и контракт агента: без копии всего шаблона

Инициализация проекта копирует в его репозиторий весь шаблон: инструменты узла, документацию, правило «ноль зависимостей». Проекту на Python это не нужно, и первый рефлекс агента — удалить лишнее, сломав гейт.

Нужно две вещи.

**1. Минимальный скелет проекта.**
Каталог скелета, из которого инициализируется репозиторий проекта:
- исполняемый `run` — единственная точка запуска, без привязки к языку;
- `PROJECT.md` с обязательными разделами (назначение, стек, команды, границы, данные, окружения, исключения);
- `test.sh` — контракт проверки: гейт запускает его, если он есть;
- `.gitignore` для артефактов и секретов;
- короткий `README.md` для самого агента проекта.

Инициализация должна принимать источник скелета, а не только корень шаблона.

**2. Контракт агента проекта.**
Документ, по которому агент приводит свой проект к узлу, без переписки:
- что обязано быть в репозитории (`run`, профиль, проверки);
- как выглядят секреты: имена переменных в профиле, значения — в файле узла, в репозиторий не попадают;
- где живут данные и почему не в коде;
- как пушить: только ветка `review`, дальше решение принимает правило;
- что запрещено: править служебные файлы узла, открывать публичные порты, запускать свои демоны, хранить секреты;
- что агент должен проверить локально до пуша.

Критерий: проект на Python заводится из скелета, гейт зелёный, `run` стартует под отдельным пользователем, данные и секреты лежат вне репозитория, Go-файлов в проекте нет.
