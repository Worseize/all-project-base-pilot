# Приёмка гейта: манифест и фикстура `proj-m`

**Что проверял:** `isolation` на ветке `fix/manifest-gate` — гейт читает
`run`/`test`/`health` из `project.conf`, фикстура собрана из скелета.

**Чем отличались прошлые падения — по условию conductor:**

1. Первое: фикстура работала в своём клоне, а deploy — в каталоге
   доставки; проверка `built.txt` смотрела не туда.
2. Второе: заглушка `run` была написана как `bash`, а `test.sh` из `main`
   компилирует `run` как Python.
3. Это: `run` восстанавливается из `BASE_MAIN:run` (тот же Python-файл,
   что в скелете), сценарий `run=app` проверяет только приём push, без
   deploy: юнит узла пока запускает `current/run`.

**Результат:** `verify` — success, `isolation` — success на `4df2cf1`
(прогон `40460641053`). Красных шагов нет; `run=app` принимается гейтом,
`run=missing` и `health` без `+x` — отклоняются.

**Что не ослаблено:** проверка режима `100755` и выбор `test` из
`project.conf` остались; `D-MANIFEST-GATE` снят с доски.
