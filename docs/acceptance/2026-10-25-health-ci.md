# CI: добавить три сценария health — дедуп, таймаут, восстановление

`deploy/ci/isolation.sh` покрывает три сценария здоровья проекта: молчание при коде 0, алерт с причиной при коде 1, отдельный алерт об отсутствии `health`.

Три других поведения реализованы, но в CI не проверяются: подавление повторов, таймаут проверки, сообщение о восстановлении. На фикстуре они работают, но регресс в них сейчас не поймает никто.

Добавить в приёмку:
1. два прохода с одной болезнью → ровно одно сообщение;
2. `health` висит дольше таймаута → одно сообщение с причиной `timeout`, проверка завершается;
3. после исправления → одно сообщение о восстановлении.

Критерий: зелёная джоба со всеми шестью сценариями, без ручных прогонов.

В 0.9.26 все шесть сценариев уже в `isolation.sh`; добавлен статический тест,
чтобы их нельзя было потерять.
