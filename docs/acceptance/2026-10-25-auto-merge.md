# Auto-merge по правилу и allowlist путей; без нейронки в приёмке

Сейчас приёмка механическая (гейт + тесты), но `main` двигает root вручную. Нужно убрать эту ручную кнопку, не теряя контроля.

**1. Auto-merge по правилу.**
Root-таймер раз в несколько минут проходит по проектам реестра и для каждого:
- если ветка `review` впереди `main`;
- и гейт по этой ветке прошёл (метка готовности с коммитом и временем);
- и коммит не старше последней метки;
то двигает `main` на этот коммит и запускает доставку в рабочий каталог проекта, затем перезапускает юнит.

Требования:
- решение принимается только по метке гейта, без анализа содержимого;
- всё пишется в журнал приёма: коммит, результат, причина отказа;
- идемпотентно: повторный проход ничего не делает;
- при провале доставки — запись в журнал и оставление `main` на прежнем коммите (или явный откат с фиксацией).

**2. Allowlist путей.**
Проект может менять только то, что ему разрешено. По умолчанию запрещены служебные файлы узла: гейт, деплой, тесты, CI, хуки. Остальное разрешается списком в реестре (например, каталог приложения и его тесты), который задаётся при онбординге и может расширяться отдельной командой root.

Проверка: коммит, трогающий запрещённый путь, отклоняется с внятным сообщением; коммит внутри разрешённого — принимается.

Критерий: после push в `review` и зелёного гейта `main` двигается сам, проект доставляется и перезапускается; попытка тронуть служебный файл отклоняется; повторный проход таймера ничего не меняет.
