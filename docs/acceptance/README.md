# Приёмка команд

Версия 0.9.12 · 24.10.2026

Здесь лежит только **публичная** история закрытых команд. Приватный
контекст, имена проектов, домены, адреса и пути хоста сюда не попадают.

## Формат файла

Имя: `YYYY-MM-DD-<slug>.md`, где `slug` — латиница, цифры и дефисы.

```markdown
# <симптом из публичной части>

<ровно публичная часть: воспроизведение, ожидание/факт>

Версия: <version>
Ссылка: findings#<номер>
```

- Тело — только содержимое между `<!-- public:begin -->` и
  `<!-- public:end -->` из issue, без правок.
- `Версия:` и `Ссылка:` обязательны.
- Пустой блок приёмки — ошибка.
- Один закрытый issue — один файл.

## Запрещено

- IPv4-литералы, `/srv/`, `/etc/`, `/home/`, e-mail, `ssh-…`;
- реальные имена проектов/агентов/владельцев, домены, IP, порты, пути;
- приватный контекст и скриншоты панели.

`python verify.py` → `check_acceptance` проверяет имя, поля и утечки.
Это механический фильтр, а не «внимательность».

## Статус

Агент пишет `published: ...` и говорит «готово, жду проверки». **Issue
закрывает только conductor** после проверки; агент не меняет состояние,
метки, исполнителей, заголовок и тело issue.
