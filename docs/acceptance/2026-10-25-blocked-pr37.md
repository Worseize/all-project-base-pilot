# blocked: PR #37 — фикстура manifest и mode-проверка

**Что проверял:** `isolation.sh` на ветке `fix/audit-bugs` (0.9.34) после
новой проверки `run`/`health` из `project.conf`.

**Точная ошибка:**

```text
remote: review rejected: missing mode missing, expected 100755
fatal: update_ref failed for ref 'refs/heads/main': ... nonexistent object
FAIL: build did not run
FAIL: python deps
FAIL: site not generated
FAIL: timezone not applied
```

**Что уже пробовал:**

1. `git add project.conf run health` в `deploy/ci/manifest.sh`.
2. `git add -f project.conf run health`.
3. push в `review` с последующим `update-ref main`.

**Причина не установлена:** хук видит `missing` для файла, который
фикстура создаёт; после отклонённого push `update-ref` падает на
несуществующем объекте, и deploy читает старый `main`.

**Чего не хватает:** одного ручного прогона с выводом:
`git ls-tree <sha> -- run health project.conf`,
`git cat-file -e <sha>` и `git config core.fileMode` в клоне фикстуры.

**Решение:** отдельный PR; не ослаблять проверку `100755` и не
отключать manifest-сценарии. #26 (SIGPIPE/свежесть/очистка) не зависит
от этого и делается отдельно.
