# Разделение файлов по аудитории и коннектор нового проекта

**1. Файл для агента не содержит задач владельца.** Файлы для агента начинаются с `Аудитория: агент <роль>`; `verify.py` (`check_handoffs`) краснеет без строки и на маркерах «владелец должен», «владельцу нужно», «попроси владельца». Задачи владельца — в отдельном документе.

**2. Коннектор агента нового проекта.** `skeleton/AGENT-CONNECTOR.md` описывает: кто на узле, что можно/нельзя, как задать вопрос, что считается «готово», роль продукта. `bootstrap-project.sh` кладёт его в корень проекта. `docs/ROLES.md` фиксирует три роли.

CI: файл без «Аудитория:» — красный; с «владелец должен» — красный с указанием вынести; онбординг даёт коннектор; проект без коннектора — красный.
