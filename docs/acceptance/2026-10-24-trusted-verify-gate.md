# Гейт обходится: verify.py берётся из пушимого дерева

Симптом: `pre-receive` распаковывает пушимый коммит и запускает `verify.py` из него. Коммит, который заменяет проверку заглушкой, проходит гейт.

Воспроизведение:
1. В рабочей копии заменить `verify.py` на скрипт, который печатает GREEN и выходит с кодом 0.
2. Закоммитить и запушить в ветку `review`.
3. Наблюдаемое: `review accepted`.

Ожидаемое: отказ, потому что проверка ослаблена тем же пушем.

Версия шаблона: 0.9.8. Окружение: Ubuntu 24.04, git 2.43, Python 3.12.
