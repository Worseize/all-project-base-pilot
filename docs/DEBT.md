# DEBT

Версия 0.9.40 · 22.10.2026

Долг — это осознанное упрощение с ценой. Запись обязательна, если код
менялся без `features/**`, `docs/adr/**` или `JOURNAL.md`; иначе
`python verify.py --close-task` краснеет.

## Открытый долг

Нет открытого долга.

| ID | Долг | Почему сейчас | Когда закрыть |
| --- | --- | --- | --- |
| D-MANIFEST-GATE | Гейт не читает `run`/`test`/`health` из `project.conf` | фикстура манифеста не сходится; эскалация conductor | после ответа по `git ls-tree` |
| D-SITE-SYMLINK | `site=static:` не проверяет symlink через `realpath` | нужна отдельная проверка и тест | до следующего аудита |
| D-HANDOFFS | `check_handoffs` не видит `TO-AGENTS-*` | новые handoff-документы не проверяются | вместе с правилом аудитории |

## Правила

- Один долг — одна строка; без «потом разберёмся».
- У долга есть владелец и срок.
- Закрытый долг **удаляется** из файла; ссылка на решение — в
  `JOURNAL.md` или `docs/adr/`.
- Закрытые долги не хранятся «для истории»: история есть в git.
- Долг не отменяет тесты, секреты и откат.
