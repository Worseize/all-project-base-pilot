# Секреты

Версия 0.9.8 · 22.10.2026

Секреты живут вне кода, вне логов и вне репозитория. В репозитории —
только имена переменных и примеры без значений.

## Где хранить

- Переменные окружения или secret manager.
- Для локальной разработки — `.env`, который не коммитится.
- В репозитории — только `.env.example` с placeholder-значениями.

## Правила

- Не печатать секреты в логи и сообщения об ошибках.
- Не коммитить `.env`, ключи, токены, private keys.
- Ротировать при подозрении на утечку.
- У каждого секрета — владелец и срок ротации.
- В CI — masked variables, не файлы в репозитории.

## Проверка

`verify.py` ищет:

- известные форматы ключей (AWS, GitHub, Slack, Telegram, OpenAI);
- присваивания `token/secret/api_key` с длинным значением;
- высокую энтропию строк;
- файл `.env` (но не `.env.example`).

Это не заменяет secret manager. История git пока не сканируется:
для неё нужен отдельный инструмент.

## Если секрет утёк

1. Отозвать/ротировать.
2. Убрать из кода и логов.
3. Проверить, где использовался.
4. Записать инцидент в `JOURNAL.md`.
5. Добавить проверку, которая поймала бы это раньше.
