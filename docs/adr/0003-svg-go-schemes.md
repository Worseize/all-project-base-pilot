# 0003. SVG-схемы на Go вместо Pillow

- **Статус:** Accepted
- **Дата:** 2026-10-22
- **Версия шаблона:** 0.9.7
- **Связанные:** RULES.md, PROCESS.md, docs/scheme-*.svg

## Контекст

Схемы рисовались Python-генераторами через Pillow. Это добавляло
build-time зависимость, требовало шрифтов и lock-файла с хешами.
PNG — бинарник: его нельзя осмысленно сравнить в диффе.

## Решение

Схемы — SVG-текст, генерируемый Go-утилитой `cmd/schemes` на stdlib.
SVG лежат в git; `verify.py` запускает `go run ./cmd/schemes -check`
и сравнивает содержимое. Lock, Pillow и шрифты не нужны.
Пользователь может открыть SVG в браузере или перегенерировать локально.

## Альтернативы

- Оставить Pillow: зависимость и бинарные файлы.
- Генерировать SVG на Python: зависимость остаётся.
- Не хранить схемы: теряется «схема — источник истины».

## Последствия

- **Плюс:** ноль зависимостей, SVG диффится как текст, нет lock.
- **Минус:** схема — текстовый outline, не пиксель-в-пиксель старый дизайн.
- **Проверка:** `verify.py` → `schemes [ok]`; устаревший SVG — красный.
