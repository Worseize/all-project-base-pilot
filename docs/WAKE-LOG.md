# Пробуждения по расписанию

Одна строка — одно пробуждение по расписанию. Если на доске есть открытые
долги `D…`, строка называет закрытый долг и живое доказательство; если
долгов нет — пишется «долгов нет». Гейт `verify.py` → `wake-debts`
краснеет без тега и доказательства при непустой доске.

| 28.10 17:59 | PENDING 2 — разобрано 2 | долгов нет | — |
| 29.10 10:19 | EMPTY | долгов нет | — |
