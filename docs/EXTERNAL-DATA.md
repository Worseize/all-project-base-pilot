# Внешние данные: снимок, подтверждение, откат

Внешние данные (таблица, API, чужая база) меняются только одним порядком:

1. **Снимок до записи.** Сохранить текущее состояние во внешний файл вне
   git и проверить, что снимок читается.
2. **Подтверждение.** Без явного «да» оператора запись только
   предлагается; флага «сделать без спроса» нет.
3. **Откат.** Из снимка, одной командой, с проверкой результата.

Снимки и секреты — вне репозитория; в git попадает только описание
контракта. Инструмент без снимка или без подтверждения — дефект.

## Проверка

`verify.py` → `external-data`: документ содержит три шага, требование
подтверждения и запрет записи без снимка.
