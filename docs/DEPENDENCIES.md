# Зависимости

Версия 0.9.55 · 25.10.2026

Шаблон — админ-узел и приёмка. Узел и его инструменты не зависят от
сторонних пакетов; стек продукта — решение отдельного проекта.

## 1. Узел и приёмка

- bash + systemd: bootstrap, хуки, baseline, deploy.
- Python 3.11+: `verify.py` и тесты gate.
- Go stdlib: `cmd/schemes` и `cmd/deadcode` — инструменты узла.

Эти инструменты не являются зависимостями продукта. Их можно заменить,
не меняя роль узла.

## 2. Продукт

Продукт живёт отдельным проектом и сам выбирает язык и зависимости.
Шаблон не требует `go.mod`, `cmd/app` или Go-код продукта.
Продуктовый проект фиксирует свой стек в `PROJECT.md` и ADR.

## 3. Инфраструктура

- GitHub Actions — verify/isolation; **опционально**.
- Caddy, ufw, fail2ban, journald, logrotate — обвязка узла.
- Branch protection — настройка платформы, не файл.
- Секреты — вне репозитория, не в `.env` проекта.

## Что запрещено у узла

- Сторонние Go-модули в инструментах узла.
- npm/Node.js и `node_modules` в шаблоне.
- Продуктовый сервис `app.service`, `cmd/app`, `bin/app`.
- Секреты в коде, логах и репозитории.

## Правило

Узел и инструменты — ноль сторонних зависимостей; продукт — выбор
отдельного проекта, зафиксированный в его профиле.
