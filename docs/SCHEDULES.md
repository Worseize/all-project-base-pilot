# Расписания: заголовок называет чат

Версия 0.9.55 · 29.10.2026

Расписание принадлежит чату, в котором создано: сработав, оно будит
именно этот чат. Поэтому в заголовке — идентификатор агента, а не
описание действия.

```text
<агент>: <что делает>
```

Правильно: `template-agent: проверка почты`. Неправильно: «Агент шаблона —
проверка сообщений», «проверка», «каждый час».

## Правило

1. Заголовок начинается с идентификатора агента, затем двоеточие и
   короткое действие: `<агент>: <что делает>`.
2. **Только свой чат.** Расписание создаётся в чате, где оно нужно;
   чужой чат — не способ разбудить другого агента.
3. Заголовок — не место для инструкций, паролей и личных данных.
4. Расписание — не задание: работу ставит владелец, расписание лишь
   говорит, когда посмотреть.
5. В простое не просыпайся: интервал — не меньше 4 часов; первый шаг
   пробуждения — проверка почты, `EMPTY` — ответ `idle` и конец.

Себе агент может завести только часовой опрос почты с заголовком
`template-agent: проверка почты` и сообщает о нём узлу.

## Проверка

`verify.py` → `schedules`: документ содержит разделы правила и проверки,
формулировки заголовка, границ и часового опроса; `AGENTS.md` ссылается
на этот файл. У узла тот же контракт проверяет его собственный скрипт
расписаний.
