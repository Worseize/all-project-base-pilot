# Карта «правило → проверка»

У каждого правила `RULES.md` есть проверка. Правило без строки здесь не
считается обязательным. Тип `авто` — запускается гейтом, у него указаны
существующий файл и тест в `tests/`; `ручная` — процедура, которую агент
выполняет и подтверждает в отчёте.

| # | Правило | Проверка | Тип |
| --- | --- | --- | --- |
| 1 | Чистый код, имена и уборка | `verify.py` — gofmt, go sizes, deadcode; `tests/test_verify.py` | авто |
| 2 | Все новые фичи — в схемах | `verify.py` — schemes; `tests/test_verify.py` | авто |
| 3 | Тесты под каждую фичу | `verify.py` — commands: go test, tests/; `tests/test_verify.py` | авто |
| 4 | Ноль сторонних зависимостей | `verify.py` — go.mod, no npm; `tests/test_verify.py` | авто |
| 5 | Схемы — источник истины | `verify.py` — schemes: SVG против документов; `tests/test_verify.py` | авто |
| 6 | Микроблоки и ООП | `verify.py` — go sizes: файл ≤ 400, функция ≤ 80; `tests/test_verify.py` | авто |
| 7 | Читать перед записью | ручная: перед правкой открыт нужный блок целиком, в отчёте — путь и строки | ручная |
| 8 | Пять минут — стоп | ручная: обдумывание дольше пяти минут → запись «сделано / не сделано / следующий шаг» и остановка | ручная |
| 9 | Проверять живо | ручная: в отчёте живой результат (вывод команды, экран, данные, CI run), не только код возврата | ручная |
| 10 | Данные и секреты | `verify.py` — secrets, logs; `deploy/debt-check.py`; `tests/test_debt_board.py` | авто |

## Похожие правила объединяются

Перед новым правилом — поиск по `RULES.md` и `AGENTS.md`: похожее правило
сливается со старым, идентичное не добавляется. Проверка
`verify.py` → `rules-dupes`: краснеет на одинаковых заголовках и на
схожести корней слов ≥ 0.7 (корень — первые пять букв слова, мера —
Жаккар). Тесты — `tests/test_verify.py`.

## Как проверяется сама карта

`deploy/rules-check.py`: десять строк ровно с номерами 1–10, тип
`авто`/`ручная`, у `авто` — существующий файл и тест в `tests/` с
`def test_`, у `ручной` — непустая процедура. `verify.py` запускает его
проверкой `rules-tests` и краснеет, если правило потеряло проверку или
файл исчез. Тест — `tests/test_rules_map.py`.
