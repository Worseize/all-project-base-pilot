# Доска долгов

Ведём только то, что ещё не снято. Снятая строка **удаляется** — история
остаётся в git. Формат единый у всех агентов: владелец читает доски
одинаково. Полное описание — `docs/TO-AGENTS-DEBT-BOARD.md`.

Теги в колонке «#»: `D…` — мой долг (снимаю сам), `W…` — задача владельца
(нужна заявка в столе), `L…` — отложено владельцем (только в чате, не в
Telegram), `N…` — задача узла (уходит письмом, на доске живёт только до
отправки).

Колонка «Кому» заполняется всегда: `я`, `владелец`, `владелец (позже)`,
для `N…` — `узел`. Итог внизу считается по строкам.
